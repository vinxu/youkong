# 冷启动功能产品需求文档

## 1. 功能概述

### 1.1 背景
有空 App 作为社交预约工具，需要帮助用户快速建立社交关系网络。传统的添加好友方式（搜索手机号、通讯录导入）在新用户冷启动阶段效率较低。

### 1.2 目标
通过**微信邀请海报 + 二维码**机制，实现：
- 用户可以快速邀请微信好友加入
- 被邀请者通过链接注册后自动建立好友关系
- 根据邀请来源智能分类好友到对应圈子

### 1.3 核心价值
```
邀请链接 = 邀请者 × 目标圈子 × 有效期
```

把「添加好友」变成「扫码即好友」，降低社交建立门槛。

## 2. 用户故事

### 2.1 邀请者视角
```
作为一个有空用户，
我想要生成一个邀请海报分享到微信群，
以便我的朋友可以快速加入并成为我的好友。
```

**验收标准：**
- [ ] 可以从圈子详情页生成邀请链接
- [ ] 可以生成包含二维码的邀请海报
- [ ] 可以设置邀请链接有效期和使用次数
- [ ] 可以查看邀请链接的使用情况

### 2.2 被邀请者视角
```
作为一个微信用户，
我想要通过扫描好友分享的二维码快速注册，
以便我可以立即使用有空并成为邀请者的好友。
```

**验收标准：**
- [ ] 扫码后可以看到邀请者信息和圈子信息
- [ ] 可以通过微信一键授权登录
- [ ] 登录后自动成为邀请者的好友
- [ ] 登录后自动加入对应圈子

## 3. 功能详情

### 3.1 邀请链接生成

#### 3.1.1 入口
- 圈子详情页 → 「邀请好友」按钮
- 个人主页 → 「邀请好友」按钮（不关联圈子）

#### 3.1.2 邀请码规则
- 长度：8位
- 字符集：`ABCDEFGHJKLMNPQRSTUVWXYZ23456789`（排除易混淆字符 I,O,0,1）
- 示例：`ABC123XY`

#### 3.1.3 邀请链接格式
```
https://youkong.app/i/{inviteCode}
```

#### 3.1.4 配置项
| 配置项 | 默认值 | 范围 |
|--------|--------|------|
| 有效期 | 7天 | 1-30天 |
| 最大使用次数 | 100次 | 1-1000次 |
| 每日创建上限 | 10个/用户 | - |

### 3.2 邀请海报

#### 3.2.1 海报元素
```
┌─────────────────────────┐
│                         │
│     [邀请者头像]         │
│     邀请者昵称           │
│                         │
│   邀请你加入「闺蜜」圈子  │
│                         │
│     ┌───────────┐       │
│     │           │       │
│     │  QR CODE  │       │
│     │           │       │
│     └───────────┘       │
│                         │
│    长按识别二维码加入     │
│                         │
└─────────────────────────┘
```

#### 3.2.2 海报尺寸
- 宽度：750px
- 高度：1334px（iPhone 6/7/8 比例）
- 二维码：300x300px

### 3.3 邀请落地页

#### 3.3.1 页面内容
- 邀请者头像、昵称
- 圈子名称、emoji、成员数
- 「微信一键登录」按钮
- 邀请有效性状态

#### 3.3.2 状态展示
| 状态 | 展示 |
|------|------|
| 有效 | 显示邀请信息 + 登录按钮 |
| 已过期 | 「邀请已过期」提示 |
| 已用完 | 「邀请名额已满」提示 |
| 已禁用 | 「邀请已失效」提示 |

### 3.4 微信登录

#### 3.4.1 授权流程
```
用户扫码 → 落地页 → 点击微信登录 → 微信授权 → 回调处理 → 注册/登录 → 进入App
```

#### 3.4.2 获取信息
- OpenID（必须）
- UnionID（如有）
- 昵称
- 头像

#### 3.4.3 账号绑定规则
- 一个微信号只能绑定一个有空账号
- 已有手机号账号可以绑定微信
- 微信登录的新用户手机号为空

### 3.5 好友关系建立

#### 3.5.1 自动建立规则
被邀请者通过邀请链接注册/登录后：
1. 与邀请者建立双向好友关系
2. 如果邀请链接关联了圈子，自动加入该圈子
3. 记录邀请关系（谁邀请的、通过哪个圈子）

#### 3.5.2 好友来源标记
| 来源 | 说明 |
|------|------|
| INVITATION | 通过邀请链接 |
| SEARCH | 通过搜索添加 |
| MANUAL | 手动添加 |

## 4. 数据模型

### 4.1 邀请链接 (Invitation)
```typescript
interface Invitation {
  id: string
  code: string              // 8位邀请码
  inviterId: string         // 邀请者ID
  circleId?: string         // 关联圈子（可选）
  maxUses: number           // 最大使用次数
  useCount: number          // 已使用次数
  expiresAt: Date           // 过期时间
  status: 'ACTIVE' | 'DISABLED' | 'EXPIRED'
  createdAt: Date
}
```

### 4.2 邀请记录 (InvitationRecord)
```typescript
interface InvitationRecord {
  id: string
  invitationId: string      // 邀请链接ID
  inviterId: string         // 邀请者ID
  inviteeId: string         // 被邀请者ID
  circleId?: string         // 加入的圈子
  createdAt: Date
}
```

### 4.3 好友关系 (Friendship)
```typescript
interface Friendship {
  id: string
  userId: string            // 用户ID
  friendId: string          // 好友ID
  source: 'INVITATION' | 'SEARCH' | 'MANUAL'
  invitationId?: string     // 关联邀请（如有）
  createdAt: Date
}
```

### 4.4 微信用户 (WechatUser)
```typescript
interface WechatUser {
  id: string
  userId: string            // 关联的有空用户ID
  openid: string            // 微信OpenID
  unionid?: string          // 微信UnionID
  nickname: string          // 微信昵称
  avatar: string            // 微信头像
  createdAt: Date
}
```

## 5. 接口设计

### 5.1 邀请模块

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|------|
| `/invitations` | POST | 创建邀请链接 | 需要 |
| `/invitations` | GET | 获取我的邀请列表 | 需要 |
| `/invitations/:code` | GET | 获取邀请详情（公开） | 不需要 |
| `/invitations/:id` | DELETE | 禁用邀请链接 | 需要 |
| `/invitations/:code/accept` | POST | 接受邀请 | 需要 |
| `/invitations/:id/poster` | GET | 获取邀请海报 | 需要 |
| `/invitations/:id/qrcode` | GET | 获取邀请二维码 | 需要 |

### 5.2 好友模块

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|------|
| `/friends` | GET | 好友列表 | 需要 |
| `/friends/:userId` | DELETE | 删除好友 | 需要 |
| `/friends/invited-by-me` | GET | 我邀请的好友 | 需要 |
| `/friends/invited-me` | GET | 邀请我的好友 | 需要 |

### 5.3 认证模块扩展

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|------|
| `/auth/wechat/login` | POST | 微信授权登录 | 不需要 |
| `/auth/wechat/bind` | POST | 绑定微信 | 需要 |

## 6. 安全设计

### 6.1 频率限制
| 操作 | 限制 |
|------|------|
| 创建邀请链接 | 10次/天/用户 |
| 接受邀请 | 10次/小时/IP |
| 微信登录 | 5次/分钟/IP |

### 6.2 邀请码安全
- 使用加密随机数生成
- 排除易混淆字符
- 不暴露用户ID等敏感信息

### 6.3 防刷机制
- 同一邀请链接同一用户只能使用一次
- 邀请链接有使用次数上限
- 邀请链接有有效期限制

## 7. 运营数据

### 7.1 关键指标
| 指标 | 说明 |
|------|------|
| 邀请链接创建数 | 用户创建邀请链接的数量 |
| 邀请链接转化率 | 实际注册数 / 链接访问数 |
| 平均邀请人数 | 每个用户平均邀请成功的人数 |
| 圈子通过邀请增长 | 通过邀请加入圈子的成员数 |

### 7.2 数据埋点
- 邀请链接创建事件
- 邀请链接访问事件
- 邀请链接转化事件
- 微信登录事件
